# Niagara-Helicopter
Code and information

1 Stepper, leadscrew for motion. Added oscillations in hover phase

Breakout board pins:
- 5v - Power for homing IR slot sensor
- 3v3 - Power for helicopter
- 3v3 - Spare
- Helicopter light signal cable - pin 15
- Homing signal cable - pin 8
- Main Rotor MOSFET output
- Main Rotor 3v3
- Tail Rotor MOSFET output
- Tail Rotor 3v3
- GND
- GND
- GND

Helicopter pad lighting to be installed later, controlled by Kevin Board

Helicopter light controls done by Attiny44 inside airframe
Helicopter light resistors:
560 Ohm Beacons
560 Ohm Nav red/White
330 Ohm Beacons
1k3 Ohm Nav green
